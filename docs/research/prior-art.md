# Prior art survey — citation-needed

Scope: what already exists (external tools + internal workspace machinery) that
overlaps citation-needed's job — extracting discrete choices from LLM-facing
artifacts, citing each (external literature first, internal provenance second),
classifying + scoring, and persisting a compounding SQLite corpus. Every
external claim below was checked this run (WebSearch/WebFetch); anything not
independently opened is marked UNVERIFIED. Every internal claim cites a
workspace `path:line`.

**Bottom line up front:** nothing surveyed does citation-needed's actual job —
"is this specific prose choice in this specific skill/rule/memory file
supported by external research literature." Eval harnesses test *model
output* against fixtures; prompt linters test *prompt structure/safety*
deterministically; citation infrastructure (Citoid/Zotero/Crossref/S2/OpenAlex)
resolves a **known reference** to structured metadata but does not **discover
whether a claim needs one** or **find one for an arbitrary prose claim**.
Internally, the workspace already has a complete judging doctrine
(`judge-core.md`), an evidence-citation discipline (`review-proof`), and a
ranked-backlog/atom-store pattern (goblin's `brain/suggestions/`) — all
reusable as-is. The one genuinely new piece of internal plumbing is the
persistent SQLite citation corpus; nothing in `.claude/skills/` writes to
SQLite today.

### 2.2 Other reusable machinery found scanning `.claude/skills/`

- **`judge-core.md`** (`.claude/skills/_shared/judge-core.md`) — the workspace's **one canonical judging doctrine**. citation-needed is, in judge-core's own taxonomy (§1, `judge-core.md:11-28`), a **judge** (backward verdict on an existing artifact) with **heavy grounding** (external literature + internal provenance) — closest to the "pointwise/absolute" + "critique-then-score" archetypes (§2, `judge-core.md:32-42`) applied per-choice, aggregated per-artifact. citation-needed's own dimension set (well-supported / needs-improvement / interesting; classifications evidence-backed / unsupported / contradicted / interesting-novel) should be run through judge-core's **§9 authoring checklist** (`judge-core.md:133-145`) before being finalized — in particular: state the archetype+dimensions explicitly, keep evidence-on-every-verdict (§5.2, already the task brief's own requirement), and build the anchored-scale-plus-worked-exemplars rubric (§4, `judge-core.md:57-67`) rather than inventing a fresh unanchored 1-5 scale. **Non-negotiable per judge-core §5.1**: the producer (the artifact's author, e.g. a past `/plan-init` session) never grades itself — citation-needed's review runs as an independent pass, which the task brief's "READ-ONLY toward targets" framing already satisfies structurally.

- **judge-core.md doctrine** — cite it, run citation-needed's rubric through its §9 authoring checklist. Do not restate its invariants in citation-needed's own docs; point at it (per `.claude/rules/knowledge-placement.md` § "one owner per contract").
